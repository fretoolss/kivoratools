# KivoraTools

A mobile-friendly, static all-in-one tools website built with HTML, CSS and vanilla JavaScript. It is suitable for GitHub Pages and does not require a build step.

## Included tools
- Word Counter
- Case Converter
- Extra Space Remover
- Percentage Calculator
- Discount Calculator
- Age Calculator
- URL Encoder & Decoder
- Password Generator

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of `fretoolss/kivoratools` (not the ZIP file itself).
2. Open **Settings → Pages** in the repository.
3. Choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
4. Wait for the Pages deployment to finish.

Website: https://fretoolss.github.io/kivoratools/
